🌡️ Celsius to Fahrenheit Converter

A simple and user-friendly web application that converts Celsius temperature to Fahrenheit instantly.
This project is built using HTML, CSS, and JavaScript and is ideal for beginners to understand basic DOM manipulation and event handling.

🚀 Features

🔢 Convert Celsius to Fahrenheit in real-time

🎯 Simple and clean user interface

⚡ Instant calculation without page reload

🧠 Beginner-friendly JavaScript logic

🛠️ Technologies Used

HTML5 – Structure of the application

CSS3 – Styling and layout

JavaScript  – Conversion logic and interactivity
